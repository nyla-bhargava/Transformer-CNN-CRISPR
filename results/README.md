This directory contains aggregated evaluation results reported in the paper.

- benchmark_summary.csv: Mean ± SD and 95% CI across 10 random seeds.
- subgroup_metrics.csv: Performance on GLOBAL, HARD (≥3 mismatches), and Top-20 recall subsets.
- statistical_tests.csv: Paired significance tests and effect sizes.
- ensemble_stats.json: Ensemble stability analysis.

Raw predictions and model checkpoints are not included due to size constraints.
All results are reproducible using the provided training and evaluation scripts.
